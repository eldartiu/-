# Практическая работа №17: Поддержка CSS Grid в различных версиях браузеров

## 1. Структура проекта
```text
practical_work_17/
├── index.html                  # Семантическая разметка каталога магазина
├── style.css                   # Таблица стилей с fallback и директивой @supports
├── screenshot_desktop_1200.png # Скриншот широкого экрана с поддержкой CSS Grid (3 колонки)
└── screenshot_mobile_375.png   # Скриншот узкого мобильного экрана (1 колонка)
```

## 2. Реализация отказоустойчивости (Graceful Degradation / Progressive Enhancement)
- **Базовый (запасной / fallback) уровень:**  
  Селектор `.shop-card` по умолчанию имеет блочное поведение и нижний внешний отступ `margin-bottom: 20px`. В старых браузерах без поддержки CSS Grid карточки аккуратно отображаются вертикальным списком.
- **Современный Grid уровень:**  
  С помощью директивы `@supports (display: grid)` проверяется поддержка свойства. При положительном ответе активируется современная сетка:  
  `display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 20px;`,  
  а свойство `margin-bottom` карточек обнуляется (`margin-bottom: 0`), чтобы отступы не удваивались с `gap`.
- **Мобильная адаптация:**  
  Медиазапрос `@media (max-width: 520px)` переключает колонки в `grid-template-columns: 1fr`, гарантируя идеальный вид на смартфонах без горизонтального скролла.

## 4. Ответы на вопросы для защиты
1. **Что делает margin-bottom и зачем оно используется в этой работе?**  
   *Ответ:* `margin-bottom: 20px` задает нижний внешний отступ для карточки товара. В этой работе оно служит резервным (fallback) механизмом разделения блоков друг от друга в старых браузерах, где не поддерживается CSS Grid и свойство `gap`.
2. **Что делает @supports и зачем оно используется в этой работе?**  
   *Ответ:* Директива `@supports (display: grid)` (CSS Feature Query) проверяет, поддерживает ли браузер пользователя указанную CSS-технологию. Она используется для прогрессивного улучшения: изолирует современные правила CSS Grid от старых браузеров, чтобы не нарушать их стабильность.
3. **Что делает auto-fit и зачем оно используется в этой работе?**  
   *Ответ:* Ключевое слово `auto-fit` в функции `repeat()` автоматически размещает в строке максимально возможное количество колонок в зависимости от доступной ширины контейнера, а оставшиеся пустые треки сжимает до 0, позволяя элементам растягиваться на всю ширину.
4. **Что делает minmax(220px, 1fr) и зачем оно используется в этой работе?**  
   *Ответ:* Функция `minmax(220px, 1fr)` задает диапазон допустимой ширины колонки: она не может быть меньше 220px, но при наличии свободного места может пропорционально расширяться (`1fr`), обеспечивая адаптивность без жестких пиксельных рамок.
5. **Что делает margin-bottom: 0 и зачем оно используется в этой работе?**  
   *Ответ:* Внутри блока `@supports` правило `margin-bottom: 0` обнуляет нижний внешний отступ карточек, предотвращая наложение/удвоение отступов, поскольку в Grid-сетке расстояние между карточками уже регулируется современным свойством `gap: 20px`.
